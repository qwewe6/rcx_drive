# RCxDrive

"Strava for RC Crawlers" — a mobile-first social/tracking app for the RC crawling
community, pairing with Racebox (and future) onboard telemetry hardware.

This repo is currently in the **planning/scaffolding phase**. No app code has been
written yet.

- Research: [`docs/research/strava-teardown.md`](docs/research/strava-teardown.md) —
  the Strava architecture/loop/revenue teardown and its translation to RC crawling.
- Plans: [`docs/plans/`](docs/plans/) — one plan doc per major initiative, starting
  with [`initial-scaffolding.md`](docs/plans/initial-scaffolding.md).

Planned stack: React Native (Expo, TypeScript), mobile-first for iOS + Android. See
the scaffolding plan for the full stack breakdown and open decisions.
